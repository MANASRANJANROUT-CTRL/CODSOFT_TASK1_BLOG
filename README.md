# InkSpace — Responsive Blog Website

InkSpace is a modern, responsive blog website developed as part of the CodSoft Frontend Development Internship. The project focuses on creating a clean, readable, and user-friendly blogging experience using HTML, CSS, and JavaScript.

The website features a responsive layout that works across desktop, tablet, and mobile devices, along with interactive features such as article search, category filtering, individual article pages, dark mode, comments, and social sharing.

## Features

- Responsive and modern blog layout
- Featured blog articles
- Responsive article cards with images, titles, excerpts, and dates
- Categories and tags
- Search functionality
- Individual article detail pages
- Load More functionality
- Responsive navigation with mobile menu
- Dark mode with theme persistence
- Client-side comment system using localStorage
- Social sharing buttons
- Copy article link functionality
- Native sharing support on compatible devices
- Liquid glass / glassmorphism UI design
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub

## Project Purpose

This project was created to demonstrate frontend development skills including responsive web design, UI development, JavaScript interactivity, DOM manipulation, browser storage, and Git/GitHub workflow.
